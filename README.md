# 🤖 AI Productivity Toolkit – Prompt Engineering

AI Productivity Toolkit is a Python-based project that demonstrates practical Prompt Engineering techniques and AI-assisted productivity workflows using Hugging Face Transformers and the FLAN-T5 model.

---

## 📌 Project Overview

This project demonstrates how different Prompt Engineering techniques can be used to perform common AI productivity tasks such as:

- Text Summarization
- Text Classification
- Text Generation
- Email Generation
- Resume Assistance
- Coding Assistance
- Debugging Assistance
- Research Assistance

The project focuses on creating effective prompts, controlling AI responses, generating structured outputs, and evaluating prompt performance.

## 🎯 Prompt Engineering Techniques

### Zero-shot Prompting

The AI performs a task without being given examples.

**Example:**
> Summarize the following text in three sentences.

---

### Few-shot Prompting

The AI is given a few examples before performing the task.

**Example:**
> Positive: I love this product.  
> Negative: This product is poor.  
> Classify: The product is excellent.

---

### Role-based Prompting

A specific role is assigned to the AI, such as a career advisor, coding assistant, or research assistant.

**Example:**
> Act as an AI career advisor and suggest skills for an AIML student.

---

### Context-based Prompting

Relevant background information is provided to improve the response.

**Example:**
> I am an AIML student learning Python. Explain machine learning in simple terms.

---

### Instructions and Constraints

Specific instructions and limitations are provided to control the output.

**Example:**
> Explain Artificial Intelligence in 5 bullet points using simple English.

---

### Structured Output

Information can be generated in a structured format such as JSON.

**Example:**

```json
{
  "topic": "Artificial Intelligence",
  "definition": "Technology that enables machines to perform intelligent tasks",
  "applications": [
    "Healthcare",
    "Education",
    "Robotics"
  ]
}
