## 🎯 Prompt Engineering Techniques

### Zero-shot Prompting

The AI is given a task directly without examples.

### Few-shot Prompting

The AI is given examples before being asked to perform a new task.

### Role-based Prompting

A specific role is assigned to the AI, such as a career advisor,
coding assistant, or research assistant.

### Context-based Prompting

Relevant background information is provided to improve the response.

### Instructions and Constraints

Specific instructions and limitations are provided to control the output.

### Structured Output

Information is generated in a structured format such as JSON.

## 📊 Prompt Evaluation

The project includes reusable prompt templates and a prompt testing
process.

Different prompts are tested using multiple test cases and checked
against expected requirements.

The evaluation helps understand whether the prompts produce the
required type of output.
